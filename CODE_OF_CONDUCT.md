# Code of conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**.

In short: be kind, assume good faith, and remember that the people this project serves (payers, inspectors, builders) aren't abstractions. Harassment, discrimination or personal attacks aren't tolerated in issues, PRs, discussions or any project space.

**Reporting:** contact the maintainer privately through GitHub (@ma-za-kpe). Reports are handled confidentially. Enforcement follows the Contributor Covenant's community impact guidelines.
